# Tauri 2

## Architecture

```
app/
├─ src/                      # frontend (React/Svelte/Vue/vanilla — any)
└─ src-tauri/
   ├─ Cargo.toml
   ├─ tauri.conf.json        # app identity, build wiring, windows
   ├─ capabilities/*.json    # v2 permission grants (replaces v1 allowlist)
   ├─ ../target/schema.json  # generated by `cargo build` — permission ground truth
   ├─ icons/
   └─ src/
      ├─ main.rs             # thin: fn main() { my_app_lib::run(); }
      └─ lib.rs              # builder chain, commands, state, plugins
```

Generate the ground-truth schema and read it before authoring capabilities:

```bash
cargo build            # produces ../target/schema.json
```

## Commands

Registration table for `generate_handler![...]`:

| Rule | Notes |
|---|---|
| `#[tauri::command]` | sync commands run on the main thread — heavy work must be `async` |
| `#[tauri::command(async)]` | forces async execution for sync signatures |
| Async commands | cannot take reference args; use owned `String`/`Vec`. `State<'_, T>` allowed. |
| Casing | JS `myArg` ↔ Rust `my_arg` (override: `#[tauri::command(rename_all = "snake_case")]`) |
| Errors | `Result<T, E>` → promise resolves/rejects. `E` must be `Serialize`, or use `Result<T, String>` |

```rust
use tauri::State;

#[tauri::command]
fn list_items(state: State<'_, AppState>) -> Vec<Item> {
    state.items.lock().expect("items mutex poisoned").clone()
}

#[tauri::command]
async fn fetch_remote(url: String) -> Result<String, CmdError> {
    // owned args only in async commands
}

// Builder chain — registration is the checklist:
tauri::Builder::default()
    .manage(AppState::default())
    .invoke_handler(tauri::generate_handler![list_items, fetch_remote])
    .run(tauri::generate_context!())
    .expect("error while running tauri application");
```

## State

- `.manage(T)` + `State<'_, T>`; requires `T: Send + Sync + 'static`.
- `std::sync::Mutex` for sync commands; `tokio::sync::Mutex` if the guard must survive an `.await`.
- Rust owns truth: if frontend and backend disagree, fix the backend event emission — don't patch JS.

use tauri::Emitter;                       // forgotten constantly — required trait

app.emit("items-changed", &items)?;       // all windows

```ts
import { listen } from "@tauri-apps/api/event";
const unlisten = await listen("items-changed", (e) => render(e.payload));
// call unlisten() on component teardown
```

Lifecycle: window close ≠ app exit. Handle `CloseRequested` to flush state or abort background tokio tasks.

## Channels (per-caller streaming — prefer over events for progress)

```rust
use tauri::ipc::Channel;

#[derive(Clone, Serialize)]
#[serde(rename_all = "camelCase")]
struct Progress { done: u32, total: u32 }

#[tauri::command]
async fn long_task(on_progress: Channel<Progress>) -> Result<(), String> {
    // real work, awaited, never blocking
    on_progress.send(Progress { done: i, total: 100 }).ok();
    Ok(())
}
```

```ts
import { Channel, invoke } from "@tauri-apps/api/core";
const onProgress = new Channel<{ done: number; total: number }>();
onProgress.onmessage = (p) => setBar(p.done / p.total);
await invoke("long_task", { onProgress });
```

`src-tauri/src/lib.rs`:

```rust
use std::sync::Mutex;

use serde::Serialize;
use tauri::State;

#[derive(Debug, Clone, Serialize)]
#[serde(rename_all = "camelCase")]
pub struct Item {
    pub id: u32,
    pub display_name: String,
}

#[derive(Default)]
pub struct AppState {
    items: Mutex<Vec<Item>>,
}

#[derive(Debug, thiserror::Error)]
pub enum CmdError {
    #[error("item {id} not found")]
    NotFound { id: u32 },
}

impl serde::Serialize for CmdError {
    fn serialize<S: serde::Serializer>(&self, s: S) -> Result<S::Ok, S::Error> {
        s.serialize_str(&self.to_string())
    }
}

#[tauri::command]
fn list_items(state: State<'_, AppState>) -> Vec<Item> {
    state.items.lock().expect("items mutex poisoned").clone()
}

#[tauri::command]
fn rename_item(id: u32, new_name: String, state: State<'_, AppState>) -> Result<(), CmdError> {
    let mut items = state.items.lock().expect("items mutex poisoned");
    let item = items.iter_mut().find(|i| i.id == id).ok_or(CmdError::NotFound { id })?;
    item.display_name = new_name;
    Ok(())
}

#[cfg_attr(mobile, tauri::mobile_entry_point)]
pub fn run() {
    tauri::Builder::default()
        .manage(AppState::default())
        .invoke_handler(tauri::generate_handler![list_items, rename_item])
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

Frontend:

```ts
import { invoke } from "@tauri-apps/api/core";

const items = await invoke<Item[]>("list_items");
await invoke("rename_item", { id: 7, newName: "Receipts" }); // newName → new_name
```

## Config essentials (v2 schema)

```json
{
  "$schema": "https://schema.tauri.app/config/2",
  "productName": "MyApp",
  "identifier": "com.example.myapp",
  "build": {
    "beforeDevCommand": "npm run dev",
    "devUrl": "http://localhost:1420",
    "beforeBuildCommand": "npm run build",
    "frontendDist": "../dist"
  },
  "app": { "windows": [{ "title": "MyApp", "width": 900, "height": 600 }] },
  "bundle": { "active": true, "targets": "all", "icon": ["icons/32x32.png"] }
}
```

- `identifier`: reverse-DNS, unique — drives app-data dirs and the updater.
- `devUrl` port must match the frontend dev server (Vite scaffold default: 1420). Mismatch → blank window.
- Set a real CSP under `app.security` for production.

## Build & mobile

```bash
cargo tauri dev            # dev build + devtools; Rust changes rebuild automatically
cargo tauri build          # release + installers
cargo tauri build --debug --bundles appimage
cargo tauri android init && cargo tauri android dev   # iOS: cargo tauri ios ...
```

Mobile: `#[cfg_attr(mobile, tauri::mobile_entry_point)]`; keep commands portable (paths via `app.path().app_data_dir()`, `use tauri::Manager;`); verify each plugin supports mobile; gate desktop-only plugins with `#[cfg(desktop)]`.

## Pitfall tables

**Tauri:**

| Symptom | Usual cause | Fix |
|---|---|---|
| `Command X not found` | not registered | add to `generate_handler![...]` |
| `invalid args` type error | casing mismatch | JS `myArg` ↔ Rust `my_arg` |
| `... not allowed` at runtime | missing permission | grant in capabilities; verify ID in `../target/schema.json` |
| UI freezes during a call | heavy sync command on main thread | make it `async` or `#[tauri::command(async)]` |
| Promise rejects with `[object Object]` | error not `Serialize` | `impl Serialize` for the error, or `String` |
| `no method named emit` | missing trait | `use tauri::Emitter;` |
| Frontend events never fire | wrong name/target or listener attached late | match event names; `emit_to` the right window label; subscribe before triggering |
| Dev window blank | `devUrl` port ≠ dev server | fix `build.devUrl` |
| Command dies silently | panic inside command | return `Result`; never panic |
| Plugin call does nothing | one of the 4 install steps missed | checklist above |

**Rust:**

| Message / symptom | Real cause | Fix |
|---|---|---|
| `cannot borrow x as mutable` | another live borrow | narrow scopes; restructure; split borrows |
| `value moved` | use after move | borrow, or `clone()` if genuinely needed |
| `Rc<RefCell<T>> cannot be sent` | non-`Send` across threads | `Arc<Mutex<T>>` |
| async task hangs forever | mutex guard held across `.await` | `tokio::sync::Mutex`, or drop the guard first |
| overflow panic (debug only) | unchecked arithmetic | `checked_*` / `saturating_*` |
| `unwrap` panic in prod path | unhandled `None`/`Err` | `ok_or_else(..)?` with context |
| trait not object safe | generic method or `self` by-value | associated types, or `&mut self` receiver |

## Testing Tauri commands

Extract pure logic from commands so it is testable without an `AppHandle` — commands are thin IPC wrappers. Need a real `AppHandle`? Enable `tauri`'s `test` feature and use `tauri::test::mock_app()`. The boundary itself is exercised by `cargo tauri dev` smoke tests.
